## 🏗 Архитектура приложения

Приложение разделено на логические страницы для обеспечения интуитивно понятного пользовательского опыта (UX):

* 🏠 **Главная** 
  * Лента актуальных объявлений.
  * Строка быстрого поиска.
* 🔍 **Расширенный поиск** 
  * Детальная фильтрация (по цене, категории, состоянию, факультету/общежитию).
* ❤️ **Избранное** 
  * Персональный список сохраненных объявлений пользователя.
* ⚙️ **Аккаунт** 
  * Управление профилем, история своих объявлений, настройки.

## 🗄 Модели данных

### 👤 Пользователь (User)
Основная сущность, обеспечивающая доверие внутри системы.
* 🛡️ **Роль:** Студент / Модератор / Администратор.
* 📇 **Контакты:** (Объект) Telegram, VK, номер телефона (скрыт по умолчанию).
* 🔗 **Избранное:** Связь один-ко-многим со списком сохраненных объявлений.
* 📝 **Доп. инфо:** Курс, факультет, номер общежития *(см. раздел TODO)*.

### 📦 Объявление (Listing)
Карточка товара, содержащая всю необходимую информацию для сделки.
* 🏷️ **Название:** Краткий и понятный заголовок.
* 🏷️ **Теги:** (Объект/Массив) Категории и ключевые слова для типизации и поиска (например: `#учеба`, `#общага`, `#электроника`).
* 🖼️ **Фотографии:** Массив ссылок на изображения товара.
* 📄 **Описание:** Детальный текст о состоянии и особенностях предмета.
* 👤 **Автор:** Ссылка на профиль пользователя (User ID).
* 📅 **Дата размещения:** Timestamp создания объявления.
* 🚦 **Статус продажи:** Активно / Продано / Снято с публикации.
